# 熊猫（xióngmāo）中国語会話

会食・飲み会・KTV・バーなど、**夜の場面の世間話**を練習するスマホ向けWebアプリです。
目標は HSK4級の範囲で、すらすら話して聞き取れるようになること。単調なドリルではなく、実際の会話の流れの中で練習します。

## できること

- **会話**（場面ごとに3つの練習）
  - 話す練習：相手のセリフを聞く → 言いたいことを日本語で選ぶ → 自分で中国語にして言う → 答え合わせ → 「言えた／あやしい／言えなかった」
  - 聞き取り：文字を隠して音だけで聞き、意味を選ぶ
  - シャドーイング：会話を流し、1文ごとの間で声に出して続ける
  - 同じ場面でも、相手の言い方・話の分かれ方・入る話題が毎回ランダムに変わります
  - 会話中の単語・つなぎ言葉に下線。タップすると意味と、ほかの会話での使われ方が見られます
- **単語**：会話に出てくる単語・接続詞・つなぎ言葉・フレーズ。穴埋め・音で選ぶ・言ってみる、の3種類で練習
- **復習**：言えなかった・あやしかった文や単語が、間をあけてもう一度出てきます（連続記録や通知はありません）
- **実力**：言えるフレーズ・聞き取れた文・言える単語の数と、場面ごと・HSKの級ごとの到達度
- **AI会話**：台本なしで場面の続きを話す。不自然なところは直してくれます（Claudeのページとして開いたときに使えます）
- **設定**：日本語→中国語／中国語を読む、相手のセリフの文字を「聞いてから」表示、ピンイン・訳、再生速度

## 使い方

ビルド不要の静的サイトです。`index.html` を開くか、GitHub Pages などで公開してスマホからアクセスしてください。

```
python3 -m http.server 8000
# → http://localhost:8000
```

## ファイル

- `js/scenes.js` 台本（場面・ターン・相手のセリフのバリエーション・分岐・学習ポイント）
- `js/words.js` 単語データ（任意。なければ台本の学習ポイントから作ります）
- `js/audio-index.js` と `audio/` 録音済み音声（`tools/make_audio.py` で生成）
- `js/app.js` アプリ本体、`css/style.css` 見た目

## 音声

場面・単語の文はすべて録音済みの音声で再生するので、端末に中国語の音声が入っていなくても普通话で聞けます。
作り方は [tools/README.md](tools/README.md)。AIの返事だけは、Claudeの音声か端末の中国語音声で読み上げます。
