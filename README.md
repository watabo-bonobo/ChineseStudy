# 夜聊（yè liáo）中国語会話

会食・飲み会・KTV・バーなど、**夜の場面の世間話**を練習するためのスマホ向けWebアプリです。
HSK2〜3級くらいの学習者が、実際に使える返し方を「自分の口で言う」ことに重点を置いています。

## できること

- **場面ロールプレイ（10場面）**：会食で初対面／乾杯とお酌／お酒を上手に断る／仕事の話（ガス安全のソフト）／お店で注文／KTV／バー／夜食の串焼き／上海の暮らし／お開きと二次会
  - 相手のセリフを音声で聞く → 言いたいことを日本語で選ぶ → 中国語で言ってみる → 答え合わせ
  - マイクが使える端末では、話した中国語を聞き取って一致度と言えなかった字を表示
  - 各場面に文化のポイント（敬酒、随意、以茶代酒 など）
- **AIと自由に話す**：台本なしで場面の続きを会話。不自然な所は直してくれます（Claudeのページとして開いた時に使えます）
- **フレーズ帳**：全フレーズを場面ごとに一覧。☆で保存
- **設定**：日本語→中国語 / 中国語を読む の切り替え、ピンイン・訳の表示、読み上げ速度

## 使い方

ビルド不要の静的サイトです。`index.html` をブラウザで開くか、GitHub Pages などで公開してスマホからアクセスしてください。

```
python3 -m http.server 8000
# → http://localhost:8000
```

読み上げは端末の音声合成（中国語の音声）を使います。iPhoneは「設定 > アクセシビリティ > 読み上げコンテンツ > 声」で中国語の音声を追加すると聞きやすくなります。

## 会話の追加

`js/scenes.js` に場面を追加するだけで増やせます。各ターンは相手のセリフ `p` と、あなたの返し方の候補 `r`（2つ）でできています。
